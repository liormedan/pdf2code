# מבנה — כל קובץ, ומה הוא עושה

שלושה תהליכים, וכל אחד מהם תיקייה. הטבלאות למטה הן **מפה ולא תיעוד** — שורה אחת לקובץ, וההנמקה בראש הקובץ עצמו. אם שורה כאן וקובץ שם סותרים זה את זה, הקובץ צודק.

התרשימים ב-[README.md](README.md). הפרוטוקול המלא ב-[engine/README.md](../engine/README.md).

```
desktop/
├── docs/                  המפה הזו
├── engine/                מנוע פייתון
├── app/
│   ├── src/               החלון — React
│   └── src-tauri/src/     המעטפת — Rust
├── spec.md  architecture.md  roadmap.md  decisions.md  backlog.md
└── sample-hebrew.pdf      קובץ בדיקה עברי
```

## המנוע — `engine/`

הצינור, לפי סדר הזרימה של מסמך.

| קובץ | מה הוא עושה |
| --- | --- |
| `main.py` | הלולאה. התהליכון הראשי **רק קורא ומנתב**; העבודה על תהליכוני daemon, ולכן ביטול מגיע באמצע עבודה ולא אחריה |
| `protocol.py` | החוט. לוקח בעלות על `stdout` מיד עם העלייה, מפנה `print` ל-`stderr`, וכופה UTF-8 על שלושת הזרמים |
| `ops.py` | **תשע הפעולות.** כל אחת מקבלת `(args, ctx)` ומחזירה את גוף ה-`result` |
| `model.py` | ה-dataclasses, מתורגמות מ-`types.ts`, כולל `round2` שמחקה את `Math.round` |
| `extract.py` | שכבת הטקסט על pdfminer — תווים, ריצות, וקואורדינטות שנגזרו ולא כוילו |
| `bidi.py` + `_bidi_tables.py` | **פורט של אלגוריתם UAX#9 מ-pdf.js.** בלעדיו העברית יוצאת הפוכה |
| `fonts.py` | נרמול שמות פונטים, כולל תחילית subset. 44 מקרים תואמים לטייפסקריפט |
| `language.py` | זיהוי שפה וכיווניות מתוך המסמך. 12 מקרים תואמים |
| `raster.py` | רינדור עמוד ב-pypdfium2, וההכרעה מתי בכלל צריך ראסטר |
| `html_out.py` | גנרטור ה-HTML. **נקרא כך כדי לא להאפיל על `html` של הספרייה התקנית** |
| `react.py` | גנרטור רכיב ה-React |
| `convert.py` | התזמור: מה רץ, באיזה סדר, ואיזו אזהרה נאספת |
| `pages.py` | **הסדנה.** תוכנית, בנייה, תמונות ממוזערות, ייצוא תמונות, הקטנה |
| `build.py` | הקפאה ב-PyInstaller `--onedir` |
| `parity/` | רתמת ההשוואה מול מנוע ה-TypeScript, ו-validator ל-HTML/JSX |

**ארבע סוויטות בדיקה, בלי מסגרת בדיקות.** `test_protocol.py` (חוזה הסיידקאר, מקבל בינארי קפוא כארגומנט) · `test_engine.py` (התאמה לטייפסקריפט) · `test_output.py` (הזרקה וסיווגי ראסטר) · `test_pages.py` (הסדנה, כולל קריטריון הסיום של ספרינט 6).

### תשע הפעולות

| פעולה | מה היא מקבלת | מה היא מחזירה |
| --- | --- | --- |
| `echo` | `value` | אותו ערך — ההוכחה הקטנה ביותר שהשרשרת שלמה |
| `sleep` | `steps`, `seconds` | כלום. קיימת כדי לתרגל התקדמות וביטול |
| `probe` | `path` | עמודים, תווים, עברית, פונטים, `scanned` |
| `convert` | `path`, `out`, `formats` | שמות קבצים, `info`, אזהרות |
| `edit` | `plan`, `out`, `overwrite` | נתיב, מספר עמודים, בייטים |
| `thumbnails` | `path`, `out`, `width` | נתיב לכל עמוד |
| `exportImages` | `path`, `out`, `pages`, `scale`, `format` | נתיב לכל תמונה |
| `compress` | `path`, `out` | לפני, אחרי, **וכמה באמת נחסך** |
| `text` | `path`, `pages` | שורות בסדר קריאה, ודגל RTL |

`probe` הוא **האופרטור היחיד שנוגע בספריות הנייטיביות**, ולכן הראשון שמריצים מול בינארי קפוא: `echo` ו-`sleep` הם פייתון טהור ויעברו גם בבניה שאיבדה את ה-DLL של PDFium.

חמש מהן מקבלות `out`, וזה בדיוק מה שמחייב את השער בצד Rust — ראה למטה.

### התוכנית

```json
[{"from": "a.pdf", "page": 3, "rotate": 90},
 {"from": "b.pdf", "page": 1}]
```

`page` מבסיס 1, כמו שאדם סופר. `rotate` הוא רבע סיבוב בלבד ו**מתווסף** למה שהעמוד כבר נושא. שש התכונות הן צורות של הרשימה הזו, ולא שש פעולות.

## המעטפת — `app/src-tauri/src/`

| קובץ | מה הוא עושה |
| --- | --- |
| `main.rs` | נקודת הכניסה |
| `lib.rs` | הבנייה, ה-setup, ו**רשימת הפקודות שהחלון רשאי לקרוא להן** |
| `sidecar.rs` | תהליך המנוע: הרצה, מסגור, `progress` כאירוע Tauri, מזהי עבודה וביטול |
| `documents.rs` | בוררי קבצים, `describe_document` שדוחה כל מה שאינו PDF, תיקיית היעד, ו-`read_output` |
| `projects.rs` | ההיסטוריה ב-SQLite. **נתיבים בלבד, ושום SQL לא חוצה את הגבול** |
| `workbench.rs` | רשימת הנתיבים שמותר לכתוב אליהם, דיאלוגי שמירה וייצוא, תיקיית הגירוד, ו-`read_image` |

### השער על הכתיבה

`engine_call` מעביר כל מה שהחלון שם ב-`args`, וחמש מתשע הפעולות מקבלות `out`. **בלי שער, פרונט שנפרץ מחזיק פרימיטיב כתיבה בכל נתיב** — דרך מנוע שיוצר תיקיות בדרך.

נתיב נכנס לרשימת המותרים בשלוש דרכים בלבד: דיאלוג שמירה נייטיבי, בורר תיקיות, או `output_dir` שיצר תיקייה בעצמו. הבדיקה קורית **לפני** שהמנוע רואה את הבקשה, ו-`output_dir` נרשם גם הוא — כך שהכלל אחיד ולא חריג של הסדנה.

**באג שהבדיקה תפסה ושימוש לא היה תופס:** הגרסה הראשונה קנוניזציה רק את ההורה, ולכן כתיבה ל-`תיקייה-שנבחרה/עוד/עמוד.png` נדחתה — בדיוק מה שייצוא תמונות יוצר בדרך.

## החלון — `app/src/`

| קובץ | מה הוא עושה |
| --- | --- |
| `components/app-shell.tsx` | החלון. **שני מצבים — המרה וסדנה — ובלי ראוטר** |
| `components/sources-panel.tsx` | הקבצים הממתינים, גרירה ובחירה מרובה |
| `components/convert-panel.tsx` | ההגדרות, הכפתור, וההתקדמות |
| `components/projects-panel.tsx` | ההיסטוריה, והרצה חוזרת |
| `components/output-preview.tsx` | תצוגה מקדימה ב-`iframe` עם `sandbox=""` |
| `components/workbench-panel.tsx` | **הסדנה:** רשת עמודים, בחירה, גרירה, סיבוב, מחיקה, שמירה, ייצוא, הקטנה, חיפוש |
| `lib/engine.ts` | המנוע כפי שהחלון רואה אותו — ארבע קריאות ומנוי אחד |
| `lib/workbench.ts` | מודל התוכנית, reducer עם ביטול לחמישים צעדים, וקריאות הסדנה |
| `lib/use-conversions.ts` | **התור הסדרתי.** כישלון לא עוצר אצווה; ביטול כן |
| `lib/projects.ts` | ההיסטוריה, בשלוש פקודות בשם |
| `i18n/` | תרגומים בשמונים שורות במקום מסגרת. `useTranslations` / `useLocale` באותן חתימות |
| `messages/he.json`, `en.json` | שתי השפות, מיובאות outright ולא נטענות |
| `components/ui/` | 16 רכיבי shadcn, `logo`, `theme-toggle`, `language-switcher` |

**הכיווניות נגזרת ולא נבחרת:** `dir` יושב על `documentElement` ולא על עוטף, ולכן CSS לוגי (`ms-`, `pe-`, `text-start`) עובד גם בפורטלים שנוצרים מחוץ לעץ של React.

# רשימת המשך — מה עושים, לפי הסדר

[roadmap.md](roadmap.md) אומר **למה** הסדר הוא הסדר. הרשימה הזו אומרת **מה לעשות מחר בבוקר**, ברמת משימה. מסמנים כאן, לא שם.

**איפה אנחנו:** ספרינט 1 בנוי ורץ בפיתוח. הוא לא נסגר, ושתי הסיבות רשומות למטה.

---

## חסמים פעילים — שלושה, ואף אחד מהם אינו קוד

| # | חסם | חוסם | מי פותר | מצב |
| --- | --- | --- | --- | --- |
| ח1 | **זיכרון מכונת הפיתוח** — 7.8GB, ~0.7GB פנויים. `link.exe` נופל ב-`LNK1102: out of memory`, ו-cargo לא מסיים אפילו את תלויות הבנייה | סגירת ספרינט 1, וכל ספרינט אחריו | אנחנו | פתוח, **הכי דחוף** |
| ח2 | **תעודת חתימת קוד** — הנפקה לוקחת ימים עד שבועות | סגירת ספרינט 1 | הנהלה ([decisions.md §2](decisions.md)) | פתוח |
| ח3 | **מסלול הגשר** — האם v0 רץ על מנוע ה-TS בזמן שהפייתון נבנה | סדר ספרינטים 2–4 | הנהלה ([decisions.md §1](decisions.md)) | פתוח |

**ח1 קודם לכול.** בלי בנייה שמסתיימת אין MSI, אין התקנה על מכונה אחרת, ואין דרך לדעת אם צד ה-Rust בכלל מתקמפל — הוא עדיין לא הגיע לקומפילציה אפילו פעם אחת.

## ספרינט 1 — סגירה · 🟡 רוב העבודה עומדת

- [x] שלד Tauri 2 + Vite 8 + React 19 + Tailwind 4 + shadcn
- [x] 16 רכיבי `ui/`, `logo`, `theme-toggle`, `language-switcher` הועברו
- [x] `app-shell` חדש — שלושה אזורים, בלי ראוטר
- [x] `next-intl` הוחלף; `useTranslations` / `useLocale` באותן חתימות
- [x] כיווניות נגזרת — אומת בזמן ריצה: `lang="he"`, `dir="rtl"`
- [x] CSP קשיח, `core:default` בלבד, בלי `fs` / `dialog` / `shell`
- [x] טייפצ'ק נקי; `vite build` עובר
- [ ] **לפתור את ח1** — אחת מהשלוש: לשחרר זיכרון ולהריץ `cargo build -j 1`; להגדיל את קובץ העימוד של Windows; או מכונת בנייה נפרדת
- [ ] `cargo check` שמסתיים — **צד ה-Rust טרם הודר ולו פעם אחת**
- [ ] `npm run bundle` מייצר MSI
- [ ] חתימה (חסום על ח2)
- [ ] **התקנה על Windows נקי שאינו מכונת הפיתוח**
- [ ] לוודא שהעברית נטענת *בתוך* ההתקנה, לא רק בפיתוח

**סיום:** מישהו אחר מתקין, וזה נפתח בעברית בלי אזהרת SmartScreen.

## ספרינט 2 — חוזה ה-IPC וסיידקאר שלד · 8%

- [ ] `engine/` — פרויקט פייתון, `requirements.txt` עם **pypdfium2** ו-**pdfminer.six** נעולים לגרסה
- [ ] לולאת NDJSON על `stdin`; **תהליכון קריאה נפרד מתהליכון העבודה**
- [ ] `sys.stdout` נחסם ללוגים מיד עם העלייה — `print` אחד מרעיל את הפרוטוקול
- [ ] `op: echo` ו-`op: sleep` שמדווחים `progress`
- [ ] `op: cancel` שעוצר תוך פחות משנייה
- [ ] צד Rust: הרצת הסיידקאר, מסגור הודעות, העברת `progress` כאירוע Tauri
- [ ] צד React: `invoke` + `listen`, פס התקדמות אמיתי, כפתור ביטול
- [ ] העברת `WarningCode`, `phase` ו-`info` מ-[types.ts](../src/converter/types.ts) — **מועתקים, לא מומצאים**
- [ ] PyInstaller `--onedir` כ-`externalBin`, ואימות **בתוך ההתקנה**
- [ ] מסלולי הכשל: סיידקאר שקרס, שנתקע, שהופעל מחדש

**סיום:** התקדמות אמיתית, ביטול מיידי, וקריסה יזומה שלא מפילה את החלון.

## ספרינט 3 — המנוע: מודל ושכבת טקסט · 20%

- [ ] `types.ts` → dataclasses: `TextRun`, `FontDescription`, `PageStats`, `PageModel`, `DocumentInfo`
- [ ] `extract` על pdfminer.six — `x`, `y`, `width`, `size`, `angle`, `font`, `rtl`
- [ ] **תרגום `fonts.ts`** — טבלאות `SERIF` / `MONO` / `BOLD` / `LIGHT` / `ITALIC` / `KNOWN`, וקילוף תחילית ה-subset
- [ ] **תרגום `language.ts`** — טווחי הסקריפטים כ-escapes, **כולל ההערה על נרמול יוניקוד**
- [ ] `PageStats` ו-`RasterHint` — ההבחנה בין עמוד מצויר לעמוד מוקלד
- [ ] זיהוי סרוק → אזהרת `SCANNED`
- [ ] רתמת השוואה: המודל של הפייתון מול המודל של ה-TS, על אותם קבצים

**סיום:** על שמונת הפיקסצ'רים, המודל תואם — בעברית, בטבלאות ובטקסט העוין.

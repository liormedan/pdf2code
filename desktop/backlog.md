# רשימת המשך — מה עושים מחר בבוקר

[roadmap.md](roadmap.md) אומר **למה** הסדר הוא הסדר ומה תנאי הסיום של כל ספרינט. הרשימה הזו אומרת **מה לעשות**, ברמת משימה. **כאן מסמנים.**

מה שכבר נבנה — ומה שכל חלק לימד — ב-[built.md](built.md). הפריטים שנשארו פתוחים בתוכו יושבים כאן בספרינט 3.

**איפה אנחנו:** קליפה שמותקנת, חוזה IPC, מנוע המרה מלא, ניהול קבצים והיסטוריה, וסדנת עמודים. **מה שחסר הוא הקצה** — הפלט נכתב לדיסק ומוצג כשורת טקסט שאי אפשר ללחוץ עליה.

## ספרינט 1 — מסירת הפלט · 10%

**הפער הגדול במוצר, והזול ביותר לסגור.**

- [ ] **פקודת פתיחת תיקייה בצד Rust** — לא `shell.open` גורף. פותחת רק נתיב שנמצא ברשימת המותרים שהשער על הכתיבה כבר מחזיק ב-`workbench.rs`
- [ ] **פתיחת הקובץ עצמו** — `index.html` בדפדפן המערכת. אותה הרשאה, אותו היקף
- [ ] **ייצוא ZIP** — להכריע: אופרטור `zip` במנוע (הוא כבר מחזיק את הקבצים) או בצד Rust (הוא כבר מחזיק את הנתיבים). המנוע סביר יותר
- [ ] **גרירה מהחלון החוצה** — Tauri תומך; לבדוק מה קורה כשגוררים תיקייה שלמה
- [ ] **העתקת נתיב ללוח**
- [ ] **רשימת הקבצים שנוצרו** בממשק, עם גודל לכל אחד. היום מוצג רק נתיב התיקייה
- [ ] **תצוגה מקדימה ל-React** — היום רק `index.html` נצפה, ו-`PdfDocument.jsx` אינו נראה בכלל
- [ ] קיצור מקלדת לפתיחת הפלט האחרון

**סיום:** ממירים מסמך, ותוך שתי לחיצות הקוד נמצא איפה שרצו אותו.

**מה שקיים כבר:** `read_output` קורא קובץ מתיקיית הפלט עם קנוניזציה ותקרת גודל, והתצוגה המקדימה רצה ב-`iframe` עם `sandbox=""`. הפתיחה החוצה היא ההרחבה, לא התשתית.

- [ ] **מסך ריצה ראשונה** — מה זה עושה, איפה הקבצים, פעם אחת וניתן לסגירה
- [ ] זכירת גודל ומיקום החלון
- [ ] קיצורי מקלדת + לוח קיצורים
- [ ] ניקוי היסטוריה ותיקיות פלט ישנות מתוך ההגדרות

## ספרינט 3 — סגירת הליבה · 12%

**תשעת הפריטים שנשארו פתוחים במה שנבנה.** מקורם ב-[built.md](built.md), והם לא נמחקו — הם עברו לכאן.

- [ ] **אימות בלחיצה: אצווה** — 40 קבצים בהרצה אחת, סגירה באמצע, פתיחה מחדש וההיסטוריה שם
- [ ] **אימות בלחיצה: סדנה** — גרירה לשינוי סדר, דיאלוג שמירה נייטיבי, ושאלת הדריסה כשבוחרים את קובץ המקור
- [ ] **סיידקאר שנתקע** — מסלול הכשל היחיד שאינו מכוסה. קריסה ויציאה נקייה כן
- [ ] **רווחים בטקסט מסובב ב-90°** — ריצה אחת מתוך 69 בפיקסצ'ר אחד. רשום ב-`KNOWN_DIFFERENCES` ומודפס בכל הרצה; **מוחקים את הרשומה כשמתקנים, לא את הבדיקה**
- [ ] **הורדת מנוע ה-TS** — חסום על שאלת האתר
- [ ] **מסמכים אמיתיים שאינם הפיקסצ'רים שלנו** — חשבוניות, טפסים, מסמכים סרוקים למחצה. שבעת הפיקסצ'רים נבחרו על ידינו, וזו הטיה
- [ ] קובץ עברי עם שם קובץ עברי, בנתיב עם רווחים — ה-UTF-8 נכפה, אבל זה לא נבדק מקצה לקצה
